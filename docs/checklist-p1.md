# Checklist da P1

Lista simples para conferir antes da entrega.

## Publicação

- [ ] Código no GitHub.
- [ ] Backend publicado.
- [ ] Frontend publicado.
- [ ] URL pública do frontend funcionando.
- [ ] URL pública do backend funcionando.

## Banco

- [ ] Projeto criado no Supabase.
- [ ] Script SQL executado.
- [ ] Tabela `lancamentos` criada.
- [ ] Tabela `limites_mensais` criada.
- [ ] Variáveis do Supabase configuradas no backend.

## API

- [ ] Testar `/api/resumo`.
- [ ] Testar listagem de lançamentos.
- [ ] Testar cadastro de lançamento.
- [ ] Testar edição de lançamento.
- [ ] Testar exclusão de lançamento.
- [ ] Testar limite mensal.

## Frontend

- [ ] Abrir a tela pela URL pública.
- [ ] Cadastrar receita.
- [ ] Cadastrar despesa.
- [ ] Editar lançamento.
- [ ] Excluir lançamento.
- [ ] Ver resumo atualizado.
- [ ] Alterar limite mensal.
- [ ] Usar filtros.

## Final

- [ ] Conferir se não tem `.env` no GitHub.
- [ ] Conferir se a documentação está coerente.
- [ ] Guardar as URLs finais para apresentar.
